### * Simulation metagenomes for strain-level diversity profiling (e.g., Cutibacterium acnes, Staphylococcus aureus, Staphylococcus epidermidis): log-normal distributed abundance

Cutibacterium acnes (n=5) + Staphylococcus aureus (n=3) + Staphylococcus epidermidis (n=3)

Cutibacterium acnes (n=5; Cutibacterium_acnes_0.01):
Simulated samples were generated by selecting Cutibacterium acnes genomes with a genetic distance exceeding 0.01 (mash distance). Each mock sample comprised 2 to 5 distinct genomes, with a total sequencing depth of 100,000 reads. The relative abundances of the constituent genomes within each sample were modeled to follow a log-normal distribution.
